# 01_Wiki — Семантическая база знаний

Слой консолидированной долгосрочной памяти: атомарные концепты, вечнозелёные заметки и глубоко связанные предметные области. Заполняется автоматически навыком [[vault-sleep-cycle]] из `00_Raw/` и поддерживается [[vault-maintenance]].

> [!IMPORTANT]
> Каждая страница имеет уникальное имя, валидный YAML frontmatter (`title`, `tags`, `category`, `status`) и связи с другими страницами через двунаправленные ссылки `[[Концепт]]`.

## Структура подпапок

| Папка | Что содержит |
|---|---|
| [`concepts/`](concepts/) | Абстрактные идеи, теории, фреймворки, методологии. «Что это / зачем». |
| [`patterns/`](patterns/) | Прикладные паттерны, техники, рецепты, workflow'ы. «Как делать». |
| [`technology/`](technology/) | Конкретные инструменты, API, фреймворки, языки, продукты с вендором. |
| [`people/`](people/) | Персоны: авторы, инфлюенсеры, эксперты. |
| [`organizations/`](organizations/) | Компании, продукты, проекты, сообщества как сущности. |
| [`sources/`](sources/) | Атомарные источники-цитаты: видео, статьи, репозитории, треды. |

## Правила раскладки

- **concepts vs patterns:** концепт — «что это / зачем» (теория, идея); паттерн — «как делать» (прикладной рецепт).
- **concepts vs technology:** концепт абстрактен и переживёт смену стека; технология — конкретный инструмент с вендором/версией.
- **organizations vs technology:** organization = реально существующее юрлицо/продукт. «Бизнес как класс» — это `concepts/`.
- **sources не создаются вручную** — их пишет [[vault-sleep-cycle]] из URL'ов в raw-заметках.
- Wikilinks `[[Имя]]` резолвятся по basename во всём vault'е — перемещение файлов между подпапками не ломает ссылки.
- При неопределённости категории — `concepts/` (дефолт).

- [[Inbox_Concepts]] — свежеконсолидированные концепты, ожидающие ручной категоризации.
